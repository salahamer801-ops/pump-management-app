## 2. API — نقاط جديدة (كلها على الخادم الحالي، `/api`)

| الطريقة | المسار | الصلاحية |
|---|---|---|
| GET | `/api/pumps/:pumpId/operating` | مسؤول المضخة أو عضو **معتمد** (قراءة) |
| PUT | `/api/pumps/:pumpId/operating` | مسؤول المضخة فقط (حفظ كامل متزامن) |
| POST | `/api/pumps/:pumpId/migrate-local` | مسؤول المضخة فقط (ترحيل مرة واحدة + علامة) |
| GET/POST | `/api/pumps/:pumpId/dialas` | قراءة / مسؤول المضخة |
| GET/POST | `/api/dialas/:dialaId/base-roster` | قراءة / مسؤول المضخة (بحارس الساعات + التثبيت) |
| POST | `/api/dialas/:dialaId/roster/lock` \| `/roster/unlock` | مسؤول المضخة (فك التثبيت بسبب موثّق) |
| GET | `/api/dialas/:dialaId/days` | قراءة |
| GET/POST | `/api/days/:dayId/actual-schedule` | قراءة / مسؤول المضخة |
| GET/POST/DELETE | `/api/me/records` | صاحب السجل نفسه فقط |

**حُرّاس على الخادم (لا في الواجهة):**
- كشف الدوام الأساسي: مجموع `shareMin` لا يتجاوز ساعات تشغيل المضخة (المثال: 20 ساعة = 1200 دقيقة → 1201 مرفوضة) — مطبَّق في مسار الحفظ الكامل وفي مسار الكشف مباشرة.
- الكشف المثبَّت: أي تغيير يُرفض (`roster_locked`) إلا بفك تثبيت بسبب موثّق (٣ أحرف على الأقل) يُسجَّل قبل/بعد.
- كل صف كشف/يوم/دور يُنسب لمضخة المسار وديالتها — لا يُقبل معرّف من مضخة أخرى.
- لا حذف نهائي: «حذف ناعم» مع من أزاله ومتى ولماذا.

## 3. Security — العزل

| الدور | ما يستطيع | ما لا يستطيع |
|---|---|---|
| **Manager** | قراءة/كتابة بيانات مضخته فقط (`pump.manager_id === req.user.id`) | مضخة مسؤول آخر (403)، منح نفسه مسؤول نظام، قراءة سجلات المستخدمين الشخصية |
| **Shareholder** | قراءة بيانات المضخة التي لديه عضوية **معتمدة** فقط + سجله الشخصي (كتابة/حذف لسجله) | أي كتابة في الكشف أو اليوم الفعلي أو إعدادات المضخة (403)، قراءة مضخة أخرى (403)، رؤية سجلات غيره |
| **System Admin** | لوحته: المستخدمون، المضخات، الطلبات، الإعدادات، سجل التدقيق | أي صلاحية تشغيلية على الديالات أو الكشوف (لا يملكها أصلًا) |

`managerId` تعني مسؤول المضخة فقط، و`is_admin` صلاحية منفصلة تمامًا — ولا يمنح Manager أي شيء منها.

## 4. Migration (من localStorage إلى PostgreSQL)

الترتيب المنفَّذ في طبقة المزامنة (`src/domain/serverSync.ts` + `src/store.tsx`):
1. **اكتشاف**: عند فتح التطبيق بحساب مسؤول يُربط رقم تعريف المضخة (`PMP-XXXXXX`) بمعرّفها على الخادم.
2. **قراءة**: `GET /api/pumps/:id/operating` — تُعرف حالة الخادم و`migratedAt`.
3. **نسخة احتياطية محلية قبل أي رفع**: `pump-org-backup-phase2::<storageKey>`.
4. **التحويل والرفع**: `payloadFromState` يحوّل الحالة إلى كيانات الخادم، ثم `POST /api/pumps/:id/migrate-local` (يرفع + يضع `migrated_at` على الخادم).
5. **التحقق**: لا تُكتب علامة الترحيل محليًا (`pump-org-migrated::<pumpId>`) إلا بعد نجاح الرفع وعودة `migratedAt`.
6. **عند الفشل**: تبقى البيانات محلية كما هي، ويُعاد المحاولة في الصف التالي — لا فقدان بيانات.
7. **لا حذف**: المفتاح المحلي `pump-org-state-v2::<pumpId>` يبقى مكانه (ذاكرة/مسودة فقط).
8. **الخادم رسمي بعد ذلك**: أي فتح لاحق ينزّل البيانات الرسمية ويستوردها (بنسخة `pump-org-backup-preimport::<storageKey>` قبل الاستبدال)، ثم كل تعديل يُرفع تلقائيًا.

**حالة localStorage بعد النقل:** إعدادات الواجهة، المضخة النشطة، ذاكرة العرض، ومسودة الجهاز — والمصدر الرسمي هو PostgreSQL.

1. **عنوان API إنتاجي + CORS** لتطبيق Capacitor (Phase 2 من تقرير فحص Android) — لم يُنفَّذ بعد.
2. **كيانات لم تُنمذَج بعد** (`rights`, `transferEvents`, `settlements`, `corrections`, `conflicts`): محفوظة على الخادم كما هي داخل `pump_sync.extra` (jsonb) فلا تُفقد، لكنها ليست جداول بعد.
